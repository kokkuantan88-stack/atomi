# Button

Buttons start an action; the label says exactly what happens ("Start lesson", "Check what I learned").

- **Primary** (`at-btn-primary`, star yellow with `on-star` text) once per screen, for the main thing the screen is for. On the dark sky it reads like a glowing star.
- **Brand** (`at-btn-brand`, glowing purple) for secondary emphasis and rewards ("Claim badge").
- **Default** for everything else; **small** (`at-btn-sm`) inside lists and rows.
- Minimum height 44 px so it is easy to tap. Verb first, sentence case, no emoji.
